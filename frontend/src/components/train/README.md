# Train map

react-three-fiber scene in blueprint style: TrainScene (Canvas, OrbitControls, Edges), Hotspots (drei Html markers
from src/config/train-parts.json, colored by case stage), PartPanel (side panel with actions), FilterBar.
Model: public/models/train.glb (see CREDITS.md). Find mesh names with `scene.traverse` and fill meshNames in the config.
